# OIBSIP Task 1 - AI Voice Assistant

This is a Python-based Voice Assistant created for the Oasis Infobyte (OIBSIP) internship task.

## Features
- Voice recognition to accept audio commands.
- Text-to-speech engine for spoken output.
- Wikipedia integration to search and answer user queries.

## Requirements & Libraries
- Python 3.12+
- SpeechRecognition
- pyttsx3
- PyAudio
- wikipedia

## How to Run
1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install SpeechRecognition pyttsx3 PyAudio wikipedia
